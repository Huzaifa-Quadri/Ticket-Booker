# ✈️ Flighters – Your Flight Booking Companion

**Flighters** is a beautifully crafted mobile UI built with Flutter that provides a sleek interface for searching flights, viewing tickets, and managing user profiles. This frontend-only app is designed to demonstrate UI/UX skills and navigation structure using Dart and Flutter.

---

## 🛠️ Tech Stack

- **Flutter** & **Dart** – Cross-platform app development  
- **Material Design** – Modern UI styling  
- **Flutter Navigation** – Multi-screen navigation flow  
- **GitHub** – Version control and collaboration

---

## ✨ Features

- 🏠 **Home Screen**  
  - Displays upcoming flights and hotel booking prompts  
  - Clean and intuitive layout for easy navigation

- 🔍 **Search Flights**  
  - Search for flights by destination and travel date  
  - Neatly organized UI to simulate a booking experience

- 🎫 **View Booked Tickets**  
  - Shows an overview of booked flights with essential travel details

- 👤 **Profile Management**  
  - Allows editing of user details and settings

---

## 🚀 Future Enhancements

- 🔄 **Backend Integration**  
  - REST APIs for real-time flight search and booking

- 🧠 **State Management**  
  - Planned use of **Provider**, **Riverpod**, or **Bloc** for data flow and performance

- 🔐 **Secure Storage**  
  - Firebase for storing user info and bookings securely
